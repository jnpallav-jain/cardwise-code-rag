One honest caveat. This demo retrieves with BM25, computed in your browser — dense embeddings would need an API key, which can't ship in a public page. The measured results in the write-up come from a dense voyage-code-4 pipeline. Same architecture, different retriever, so don't read this demo's hit rate as the eval's number.

Answers are generated by Claude, in your session, from the retrieved chunks only — it has no other access to the repository.
